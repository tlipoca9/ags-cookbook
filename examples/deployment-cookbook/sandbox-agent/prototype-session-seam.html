    模型所依据的固定事实

    • /opencode 在 v0.4.2 创建 backing session 时不设置 agent_mode，因此不能证明 codex/auto。
    • native TypeScript SDK 使用 first-party streamable HTTP：JSON-RPC 通过 POST，事件通过 SSE；它会在 mode 存在时调用 setSessionMode，在 model 缺省时不设置 model。
    • SDK 默认 driver 只在内存中保存 session record 和 event；断开后恢复必须提供 durable SessionPersistDriver。
    • 新连接恢复时，SDK 保留 local session ID，但创建新的 backing agent session，并把事件历史注入下一条 prompt；这不是 backing identity continuity。
    • AGS persistent Tool + EXCLUSIVE affinity + PAUSE 仍需在 Shanghai 实测 workspace byte continuity。这里把它建模为候选合同，不冒充云上证据。
